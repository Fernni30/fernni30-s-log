
## 1. 개요

> 악성코드가 설치된 피해자 PC와 공격자 서버 사이에 **원격 제어 채널을 개설**하는 단계입니다.

- C2 Beaconing = 감염된 호스트가 C2 서버에 **주기적으로 신호를 보내며** 통신을 유지하는 것

---

## 2. C2 통신 방식의 변화

| 시대  | 방식                            | 현황                            |
| --- | ----------------------------- | ----------------------------- |
| 과거  | **IRC (Internet Relay Chat)** | 현대 보안 솔루션이 쉽게 탐지 → 사실상 사용 안 함 |
| 현재  | HTTP/HTTPS, DNS 등             | 정상 트래픽으로 위장해 탐지 회피            |

---

## 3. 주요 C2 채널

> 1. HTTP/HTTPS (포트 80/443)

- 일반 웹 트래픽과 **섞여서** 악성 통신을 위장
- 방화벽이 80/443 포트를 기본적으로 허용하므로 **차단 어려움**
- HTTPS는 암호화까지 되어 있어 내용 분석도 까다로움

> 2. DNS Tunneling

- DNS 프로토콜을 통신 수단으로 악용 (DNS 쿼리 안에 데이터를 숨겨 통신)
- 감염된 호스트가 공격자 소유의 DNS 서버로 **지속적인 DNS 요청**을 보냄
- DNS 트래픽은 대부분 허용되어 있어 **탐지 회피에 효과적**

---

## 4. 대응책

- **비정상적인 DNS 쿼리 패턴** 모니터링 (DNS Tunneling 탐지)
- **IDS/IPS**로 비콘 패턴(주기적 통신) 탐지
- **트래픽 분석(DPI)** 으로 정상 트래픽 속 악성 통신 식별
- **Threat Intelligence** 기반 C2 서버 IP/도메인 차단
