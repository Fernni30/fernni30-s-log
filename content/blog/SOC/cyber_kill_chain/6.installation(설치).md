
## 1. 개요

> 공격자가 시스템에 대한 **지속적인 접근(Persistence)을 확보**하는 단계입니다. 연결이 끊기거나 초기 접근이 제거되거나 시스템이 패치되더라도 **다시 접속할 수 있는 백도어를 심습니다.**

---

## 2. 지속성 확보 방법 (Persistence Techniques)

> 1. 웹 셸 (Web Shell)

- ASP, PHP, JSP 등 웹 언어로 작성된 악성 스크립트를 웹 서버에 설치
- `.php`, `.asp`, `.jsp` 등 일반 웹 파일과 형식이 같아 **탐지가 어려움**
- 정상 파일로 오인될 가능성 높음

> 2. 백도어 설치 (Meterpreter)

- **Meterpreter**: Metasploit Framework의 페이로드
- 공격자가 피해자 PC를 **원격에서 인터랙티브 셸로 제어** 가능
- 악성 코드 실행, 파일 접근 등 광범위한 원격 조작 가능

> 3. Windows 서비스 생성·변조 (T1543.003)

- 악성 스크립트·페이로드를 **Windows 서비스로 등록**해 정기 실행
- 사용 도구: `sc.exe`, `Reg`
- **위장(Masquerade)** 기법으로 OS나 정상 소프트웨어 서비스명을 사칭

> 4. 레지스트리 Run 키 / 시작 폴더 등록 (T1547.001)

- 레지스트리 `Run` 키 또는 시작 프로그램 폴더에 페이로드 등록
- **사용자 로그인 시마다 자동 실행**
- 개별 사용자 계정용 / 시스템 전체 적용 두 가지 위치 존재

---

## 3. 탐지 회피 기법

> 1. Timestomping (타임스톰핑, T1070.006)

악성 파일의 **타임스탬프를 조작**해 정상 파일처럼 위장

|조작 가능한 타임스탬프|설명|
|---|---|
|**Modified**|파일 수정 시간|
|**Accessed**|파일 접근 시간|
|**Created**|파일 생성 시간|
|**Changed**|메타데이터 변경 시간|

→ 포렌식 수사관이 타임라인 분석 시 **악성 파일을 정상으로 오인**하게 만듦

---

## 4. 대응책

- 웹 서버 파일 무결성 모니터링 (FIM)
- 레지스트리·서비스 변경 감지 (EDR)
- 의심스러운 시작 프로그램 주기적 점검
- 포렌식 시 타임스탬프만 믿지 말고 다각도 분석 필요
