## 1. 개요

> Cyber Kill Chain의 **첫 번째 단계**로, 공격자가 타겟에 대한 정보를 수집하고 계획을 세우는 단계입니다. 인프라 구조, 직원 정보, 비즈니스 프로세스, 노출된 기술 등을 수집하며, **대부분 피탐지 없이 조용히 진행**됩니다.

---

## 2. 정찰 유형

| 유형                    | 설명          | 예시                                   |
| --------------------- | ----------- | ------------------------------------ |
| Passive Recon (수동 정찰) | 타겟과 직접 접촉 X | WHOIS 조회, SNS 스크래핑, 유출 데이터 검토, OSINT |
| Active Recon (능동 정찰)  | 타겟과 직접 접촉   | 소셜 엔지니어링, 포트 스캐닝, 배너 그래빙, 서비스 탐색     |
- 정찰은 공격 성공률을 결정짓는 가장 중요한 초기 단계
- 능동 정찰(포트 스캐닝 등)은 로그에 흔적이 남을 수 있어 탐지 가능성이 있음

---

## 3. OSINT (Open-Source Intelligence)

> 공개된 정보 소스를 통해 타겟 정보를 수집하는 기법으로 정찰의 핵심 수단입니다.

- 검색 엔진
- 온/오프라인 미디어
- 소셜 미디어 계정
- 온라인 포럼 및 블로그
- 공공 기록 데이터베이스
- WHOIS 및 기술 데이터

---

## 4. 이메일 하베스팅 (Email Harvesting)

> 공개·유료·무료 서비스에서 이메일 주소를 수집하는 과정으로, **피싱 공격의 사전 준비**로 활용됩니다.

| 도구                  | 설명                                       |
| ------------------- | ---------------------------------------- |
| **theHarvester**    | 이메일, 이름, 서브도메인, IP, URL 등을 여러 공개 소스에서 수집 |
| **Hunter.io**       | 도메인 기반 연락처 정보(이메일) 검색                    |
| **OSINT Framework** | 카테고리별로 정리된 OSINT 도구 모음, 웹 기반             |

---

##### 답: **OSINT Framework**
