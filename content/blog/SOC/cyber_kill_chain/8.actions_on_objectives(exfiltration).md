## 1. 개요

> Cyber Kill Chain의 **마지막 단계**로, 공격자가 6단계를 거쳐 확보한 접근권으로 **최초 목표를 실제로 실행**하는 단계입니다. 이 단계에서 공격자는 키보드로 직접 시스템을 조작합니다.

- 이 단계까지 도달했다면 **이미 심각한 피해가 발생한 상태**
- 때문에 앞선 1~6단계에서 **조기 탐지·차단이 핵심**

---

## 2. 주요 공격 행동

| 행동               | 설명                                      |
| ---------------- | --------------------------------------- |
| **자격증명 수집**      | 사용자 계정 정보(ID·PW) 탈취                     |
| **권한 상승**        | 일반 워크스테이션에서 도메인 관리자 권한까지 획득 (잘못된 설정 악용) |
| **내부 정찰**        | 내부 소프트웨어와 상호작용하며 추가 취약점 탐색              |
| **수평 이동**        | 내부 네트워크의 다른 시스템으로 확산                    |
| **데이터 수집·유출**    | 민감한 데이터 수집 후 외부로 반출 (Exfiltration)      |
| **백업·섀도우 카피 삭제** | 복구 수단 제거 → 랜섬웨어 공격 시 주로 사용              |
| **데이터 덮어쓰기·손상**  | 데이터 파괴로 업무 마비 유도                        |

> **Shadow Copy**: Microsoft의 파일 백업·스냅샷 기술로, 공격자는 복구를 막기 위해 이를 우선적으로 삭제합니다.

---

## 3. 공격 목적별 분류

| 목적           | 해당 행동               |
| ------------ | ------------------- |
| **스파이활동**    | 자격증명 수집, 데이터 유출     |
| **랜섬웨어**     | 백업 삭제, 데이터 암호화·손상   |
| **내부 침투 확대** | 권한 상승, 수평 이동, 내부 정찰 |

---

## 4. 대응책 

- **최소 권한 원칙(Least Privilege)** 적용
- **DLP(Data Loss Prevention)** 로 데이터 유출 감지
- **백업의 오프라인·격리 보관** (랜섬웨어 대비)
- **네트워크 세그멘테이션** 으로 수평 이동 차단
