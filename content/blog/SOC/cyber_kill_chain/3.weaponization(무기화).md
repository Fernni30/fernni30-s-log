
## 1. 개요

> 정찰 단계에서 수집한 정보를 바탕으로 **실제 공격에 사용할 무기(악성코드·익스플로잇)를 제작**하는 단계입니다.

- 일반 공격자: 자동화 툴 사용 or **다크웹에서 구매**
- 고급 공격자(APT, 국가 지원 그룹): **커스텀 악성코드 직접 제작** → 탐지 회피 목적

---

## 2. 핵심 용어 정리

| 용어                  | 설명                                |
| ------------------- | --------------------------------- |
| **Malware (악성코드)**  | 시스템을 손상·방해하거나 무단 접근하기 위해 설계된 프로그램 |
| **Exploit (익스플로잇)** | 애플리케이션·시스템의 취약점을 이용하는 코드나 프로그램    |
| **Payload (페이로드)**  | 공격자가 시스템에서 실행하는 실제 악성 코드          |

---

## 3. 주요 무기화 전술

| 전술 | 설명 |  
|------|------|
| **악성 Office 문서** | 매크로(VBA 스크립트)가 삽입된 Word·Excel 파일 제작 |  
| **감염 USB 배포** | 웜(Worm)이 심긴 USB를 공공장소에 배포 |  
| **C2 인프라 구축** | 피해자 PC에서 명령 실행·추가 페이로드 전달을 위한 C&C 서버 셋업 |  
| **백도어 삽입** | 보안 메커니즘을 우회해 시스템에 지속적으로 접근 가능한 통로 확보 |  
| **피싱 템플릿 제작** | 정상적으로 보이는 피싱 이메일 또는 OAuth 동의 앱 위장 |

---

## 4. 대응책 

- **매크로 비활성화**, **이메일 첨부파일 필터링**, **EDR 솔루션** 등이 주요 대응책
- 커스텀 악성코드일수록 **기존 시그니처 기반 백신으로 탐지 불가** → 행위 기반 탐지 필요
