## 1. SOC

> 조직의 디지털 자산을 **모니터링하고 보호**하기 위한 중앙 집중식 보안 센터입니다.  
> 사람 + 프로세스 + 기술의 조합으로 운영됩니다.

### 1) 주요 기능

| 기능                | 설명                                                       | 예시                                 |
| ------------------- | ---------------------------------------------------------- | ------------------------------------ |
| **모니터링 & 탐지** | SIEM을 통해 네트워크 내 의심 활동을 지속적으로 감시        | 비정상적인 로그인 시도 탐지          |
| **복구 & 대응**     | 위협 식별 시 EDR, 방화벽, IAM 등을 활용해 즉각 조치        | 감염된 엔드포인트 격리, 악성 IP 차단 |
| **위협 인텔리전스** | 최신 위협 정보(IP, 해시, 도메인 등)를 지속적으로 수집·활용 | 악성 도메인 차단                     |
| **커뮤니케이션**    | IT팀, 경영진과 협력하여 위협 상황 공유 및 대응 조율        | IT팀에 패치 검증 티켓 발행           |

### 2) 한계

| 한계                             | 설명                                                                                                          |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 알림 피로 (Alert Fatigue)        | 너무 많은 보안 도구 → 알림 폭주 → 대부분 오탐(False Positive)<br>정작 중요한 위협을 놓칠 위험                 |
| 도구 파편화 (Disconnected Tools) | 방화벽, 엔드포인트 보안 등 각 도구들이 통합 없이 독립적으로 운영<br>분석가가 여러 툴을 수동으로 넘나들어야 함 |
| 수동 프로세스 (Manual Processes) | 조사 절차가 문서화되지 않고 베테랑 분석가의 경험에만 의존<br>대응 속도 저하, 인수인계 문제 발생               |
| 인력 부족 (Talent Shortage)      | 보안 전문 인력 채용 어려움<br>과중한 업무 → 번아웃 → 대응 지연 → 피해 확대                                    |

### 3) 문제

#### Q. How would you describe the experience of an overload of security events being triggered within a SOC?

##### 답: Alert Fatigue

앞서 애기한 내용 중 알람 피로(Alert Fatigue)에 대한 내용이다.

## 2. SOAR

> SOC에서 사용하는 **모든 보안 도구를 하나로 통합**하는 플랫폼입니다.  
> 분석가가 SIEM, EDR, 방화벽 등을 따로 오가지 않고 단일 인터페이스에서 모두 운영할 수 있으며,
> 티켓팅 & 케이스 관리 기능도 함께 제공합니다.

### 1) 기능

#### a. 오케스트레이션 (Orchestration)

- 여러 보안 도구를 SOAR 내에서 하나로 연결·조율
- 플레이북(Playbook) 을 통해 알림 유형별 조사 절차를 미리 정의 - 워크플로우 정의
- 각 단계의 결과에 따라 다음 행동이 동적으로 결정됨

> 예) VPN 무차별 대입 공격 알림 플레이북:
>
> SIEM에서 알림 수신 → 사용자의 해당 IP 사용 이력 확인 → TI 플랫폼으로 IP 평판 조회 → 성공적인 로그인 여부 확인 → 차단 조치 에스컬레이션

#### b. 자동화 (Automation)

- 플레이북의 모든 과정을 **자동으로 실행** (수동 클릭 불필요)
- SOAR가 스스로 SIEM 조회 → IP 평판 확인 → 사용자 비활성화 → 티켓 생성까지 처리
- 분석가 번아웃 없이 **수백 건의 알림 처리** 가능

#### c. 대응 (Response)

- 단일 인터페이스에서 **실제 차단 조치**까지 수행
- 방화벽 IP 차단, IAM 사용자 비활성화, 티켓 생성 등을 자동으로 연계 실행

> SOAR는 분석가를 **대체하는 것이 아니라**, 반복 업무를 줄여 더 중요한 일에 집중할 수 있게 **보조하는 도구**입니다. AI를 통해 SOAR 분석가의 역할을 좀 더 세분화되고 전문화될 것이다.

### 2) 문제

#### Q. The act of connecting and integrating security tools and systems into seamless workflows is known as?

##### 답: Orchestration

#### Q. What do we call a predefined list of actions to handle an incident?

##### 답: Playbook
