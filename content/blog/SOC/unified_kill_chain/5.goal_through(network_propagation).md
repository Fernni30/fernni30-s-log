
## 1. 개요

**초기 거점 확보 이후**의 단계입니다. 방어 통제 때문에 목표를 바로 달성하지 못하면, 공격자는 **추가 접근권과 권한**을 얻으려 합니다. 한 시스템을 **기지(피벗 지점)** 로 삼아 내부 네트워크 정보를 수집하고 이동합니다. (UKC 3개 그룹 중 **Network Propagation**에 해당)

---

## 2. 단계별 요약

| 단계                                | 핵심 내용                                                                              | 세부 내용                                                                 |
| --------------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **Pivoting** (TA0008)             | 장악한 시스템을 **작전 기지**이자 공격자 C2와 피해자 네트워크 사이의 **터널**로 사용. 이후 악성코드·백도어의 **배포 지점**으로도 활용 | -                                                                     |
| **Discovery** (TA0007)            | 시스템과 연결된 네트워크 정보를 파악해 지식 베이스 구축                                                    | 활성 사용자 계정과 권한, 사용 중인 애플리케이션·소프트웨어, 웹 브라우저 활동, 파일·디렉터리·네트워크 공유, 시스템 설정 |
| **Privilege Escalation** (TA0004) | 수집한 정보와 취약점·설정 오류를 이용해 **더 높은 권한** 획득                                              | SYSTEM/ROOT, 로컬 관리자, 관리자급 접근권이 있는 사용자 계정, 특정 접근권·기능을 가진 사용자 계정        |
| **Execution** (TA0002)            | 피벗 시스템을 호스트로 삼아 **악성 코드 배포·실행**. 시스템에서의 반복적 존재와 지속성 유지가 목적                         | 원격 트로이목마(RAT), C2 스크립트, 악성 링크, 예약 작업                                  |
| **Credential Access** (TA0006)    | 계정명·비밀번호 탈취. 정상 자격증명을 쓰기 때문에 **탐지가 더 어려워짐**                                        | 키로깅, 크리덴셜 덤핑                                                          |
| **Lateral Movement** (TA0008)     | 탈취한 자격증명과 높은 권한으로 **다른 시스템으로 이동**. 은밀할수록 유리                                        | -                                                                     |

## 3. 문제

#### Q. As a SOC analyst, you pick up an alert pointing to failed logins from an administrator account.  What phase of the Unified Kill Chain would an attacker be seeking to achieve?

>SOC 분석가로서, 관리자 계정의 로그인 실패를 알리는 경보를 확인했습니다. 공격자는 통합 킬 체인(Unified Kill Chain)의 어떤 단계를 달성하려고 할까요?

##### A. Privilege Escalation

#### Q. Mimikatz, a known post-exploitation tool, was detected on the IT Manager's workstation.  The Security logs show that the tool was attempting to dump OS and user secrets.  Which Unified Kill Chain phase does this activity correspond to?

> IT 관리자의 워크스테이션에서 잘 알려진 포스트 익스플로잇 도구인 Mimikatz가 탐지되었습니다.보안 로그에 따르면, 이 도구는 OS 및 사용자 비밀 정보를 추출하려고 시도한 것으로 나타났습니다.이 활동은 통합 킬 체인(Unified Kill Chain)의 어느 단계에 해당합니까?

##### A. Credential Access
