## 1. 개요

> 공격자가 시스템이나 네트워크 환경에 처음 접근해 발판을 마련하는 일련의 단계입니다.

---

## 2. 단계별 요약

| 단계                              | 핵심 내용                                    | 예시                                                                      |
| ------------------------------- | ---------------------------------------- | ----------------------------------------------------------------------- |
| **Reconnaissance** (TA0043)     | 능동·수동 정찰로 타겟 정보 수집. 이후 모든 단계에 활용됨        | 실행 중인 시스템·서비스 파악, 직원 목록 확보(사칭·피싱용), 크리덴셜 탐색, 네트워크 구조 파악(피벗용)            |
| **Weaponization** (TA0001)      | 공격에 필요한 **인프라 준비**                       | C2 서버 구축, 리버스 셸 수신 및 페이로드 전달 시스템                                        |
| **Social Engineering** (TA0001) | 직원을 **조작해 공격에 도움이 되는 행동**을 하게 함          | 피싱 메일의 악성 첨부파일 열기, 가짜 웹페이지에 자격증명 입력, 전화·방문해 사칭(비밀번호 재설정 요청, 유틸리티 기사 사칭) |
| **Exploitation** (TA0002)       | 취약점을 악용해 **코드 실행**(UKC의 정의)              | 웹 애플리케이션에 리버스 셸 업로드·실행, 자동화 스크립트에 간섭, 웹 취약점으로 코드 실행                     |
| **Persistence** (TA0003)        | 초기 접근한 시스템에 **계속 접근**할 수단 유지             | 재접속용 서비스 생성, C2 서버에 시스템 등록, 특정 행동 시 실행되는 백도어(관리자 로그인 시 리버스 셸 실행)        |
| **Defence Evasion** (TA0005)    | 시스템·네트워크의 **방어 수단 회피**                   | WAF, 네트워크 방화벽, 안티바이러스, IDS 회피                                           |
| **Command & Control** (TA0011)  | 무기화 단계의 준비를 바탕으로 공격자와 타겟 시스템 간 **통신 확립** | 명령 실행, 데이터·자격증명 탈취, 장악한 서버를 이용해 다른 시스템으로 피벗                             |
| **Pivoting** (TA0008)           | 외부에서 직접 접근할 수 없는 **내부 시스템으로 이동**         | 공개된 웹 서버를 장악한 뒤 같은 네트워크의 비공개 시스템 공격                                     |

## 3. 문제

#### Q. What is an example of a tactic to gain a foothold using emails?

> 이메일을 활용해 발판을 마련하는 전술의 예로는 무엇이 있을까요?

##### A: Phishing

이메일을 활용하여 악성 사이트 접속 유도하는 공격 방법

#### Q. Impersonating an employee to request a password reset is a form of what?

> 직원으로 위장하여 비밀번호 재설정을 요청하는 행위는 어떤 유형에 해당합니까?

##### A: Social Engineering

#### Q. An adversary setting up the Command & Control server is what phase of the Unified Kill Chain?

> 명령 및 제어(C&C) 서버를 구축하는 공격자는 통합 킬 체인의 어느 단계에 해당합니까?

##### A: Weaponization

공격에 사용할 C2 서버 구축은 Weaponization에 해당합니다.

#### Q. Exploiting a vulnerability present on a system is what phase of the Unified Kill Chain?

> 시스템에 존재하는 취약점을 악용하는 것은 통합 킬 체인의 어느 단계에 해당합니까?

##### A: Exploitation

#### Q.  Moving from one system to another is an example of?

> 한 시스템에서 다른 시스템으로 이동하는 것은 다음 중 무엇에 해당합니까?

##### A: Pivoting

#### Q. Leaving behind a malicious service that allows the adversary to log back into the target is what?

> 공격자가 대상 시스템에 다시 로그인할 수 있게 해주는 악성 서비스를 남겨두는 것을 무엇이라고 합니까?
##### A: Persistance
