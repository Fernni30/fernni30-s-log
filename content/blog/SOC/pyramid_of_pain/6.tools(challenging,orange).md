
## 1. tools단계

> 방어자가 Tools 단계까지 탐지하면 공격자는 사실상 게임 오버에 가까움
  
- 공격자의 선택지:
    - 새로운 도구를 **돈 들여 직접 개발**
    - 같은 기능의 **대체 도구 탐색**
    - 새 도구 사용법을 위한 **재훈련**
      
- 모두 **시간 + 비용 + 노력** 소모 → 공격자에게 가장 큰 고통 중 하나

## 3. Fuzzy Hashing (유사도 분석)

> 파일 간 **미세한 차이가 있어도 유사도 비교** 가능

- 대표 도구: SSDeep (풀네임:  context triggered piecewise hashes)
- 활용: 악성코드 변종 탐지, VirusTotal에서도 SSDeep 해시 제공

```
# SSDeep 비교 예시
원본 악성코드  →  ssdeep 해시 A
변형 악성코드  →  ssdeep 해시 B
→ A와 B의 유사도 % 계산 가능
```
